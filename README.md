# namorada
Nosso Amor é um site romântico e interativo desenvolvido para celebrar a história de um casal. O projeto reúne fotos, mensagens carinhosas, animações e um Mini Gamer com jogos, desafios e pontuação competitiva. Desenvolvido com HTML, CSS e JavaScript, busca unir programação, criatividade e romantismo em uma experiência digital personalizada.
